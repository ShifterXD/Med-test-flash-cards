# FSP Flash Cards — Spaced Repetition

Статический сайт на HTML/CSS/JavaScript с упрощённой Anki-like логикой повторений.

## Запуск

```bash
python3 -m http.server 8000
```

Открыть:

```text
http://127.0.0.1:8000/
```

Важно: открывать через локальный сервер, потому что браузеры часто блокируют `fetch('cards.json')` при `file://`.

## Что реализовано

- карточки загружаются из `cards.json`;
- после кнопки «Показать ответ» появляются 3 оценки: «Не знаю», «Сложно», «Легко»;
- оценки меняют расписание:
  - «Не знаю» — короткий repeat delay и повтор в текущей очереди через пару карточек;
  - «Сложно» — короткий интервал и повтор в текущей очереди позже;
  - «Легко» — интервал увеличивается сильнее;
- прогресс, интервалы, ошибки и due dates сохраняются в `localStorage` под ключом `fsp-flashcards-srs-v1`;
- кнопка «Сбросить прогресс» очищает расписание повторений;
- слабые карточки имеют повышенный приоритет и возвращаются чаще.

## Файлы

- `index.html` — интерфейс приложения.
- `styles.css` — адаптивная верстка.
- `app.js` — spaced repetition, localStorage, управление карточками.
- `cards.json` — 279 карточек из `FSP Stuttgart.docx`.
- `cards.csv` — те же данные в CSV.
- `cards.schema.json` — описание формата карточек.
- `build_cards.py` — воспроизводимая генерация deck из исходного DOCX attachment.
- `extracted/FSP Stuttgart.txt` — извлечённый текст source DOCX.

## Горячие клавиши

- `Enter` или `Space` — показать ответ.
- `1` — Не знаю.
- `2` — Сложно.
- `3` — Легко.
